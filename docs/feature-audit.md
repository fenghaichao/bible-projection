## 一、界面结构

| 区域 | 位置 | 说明 |
| --- | --- | --- |
| 顶栏 | `src/renderer/index.html` | 品牌、**译本下拉框 + 「获取译本」按钮**、抽屉入口（查找 / 历史 / 收藏 / 设置 / 帮助）、投影按钮、浮动面板总开关 |
| 左侧目录栏 | `#sidebar` | 四级视图：分类 → 书卷 → 章节 → 节号 |
| 舞台 | `#stage-scroll > #verses` | 经文正文；`canvas#draw-canvas` 覆盖其上作为标注层 |
| 抽屉 | `#drawer` | 5 个面板：查找 / 设置 / 历史 / 收藏 / 帮助 |
| 浮动控制面板 | `src/renderer/float.html` + `float.css` + `js/float.js` | **第二个 BrowserWindow**，无边框置顶浮窗，5 个标签页 |

浮动控制面板的 5 个标签页为：经文选择、查找、格式、新约、旧约。
其中「新约 / 旧约」两个标签页是**真实目录**：新约 27 卷、旧约 39 卷，点某一卷会让主窗口跳到该卷第 1 章。
「格式」页提供字号 ± 与主题切换。

## 六、未实现 / 有意不实现（附原因）

| 项 | 原因 |
| --- | --- |
| 经文语音朗读、单节 / 多节 / 单章 / 连续朗读 | 原程序是**有声版**才有朗读；本项目重写的是**无声版**，按原软件定位一律不实现 |
| LRC 歌词同步高亮 | 同上，没有语音即没有朗读同步 |
| 朗读播放控制栏、`+` / `-` 播放速度、`Insert` / `Delete` 朗读控制、`Ctrl+Enter` / `Ctrl+End` 朗读定位 | 同上 |
| 原版**透明窗口**（`F7`） | 需要主进程 `BrowserWindow` 的额外能力（透明 + 置顶 + 穿透），本版未做；`F5` 进 / 出投影、`F11` 原生全屏已覆盖常用场景 |
| 原版**桌面扩展**（`F9`） | ✅ **已实现为「投影到副屏」**：`F9` 或右键「扩展桌面_F9」在第二个显示器上开一个无边框全屏窗口，显示与主窗口同步的经文（字号、颜色、背景图、阴影都跟随主窗口设置），再按一次关闭；只有一块屏时提示「未检测到第二个显示器」。详见 [docs/architecture.md](architecture.md) §9 |
| 原版 `Ctrl+0`…`4`「隐藏全部对照栏」语义 | **有意取舍**：本版已移除对照栏功能（2026-11-11 按用户要求删除），`Ctrl+0` 只用于复位字号。原语义会让用户在投影时误按 `Ctrl+0` 导致内容全空 |
| 无线遥控器硬件适配 | 没有做硬件协议适配；键盘媒体键（上一曲 / 下一曲）可当翻节遥控使用 |
| 多窗口同屏显示不同经文 | 原版有此能力；本版为单窗口 + 一个浮动控制面板（多栏对照已移除） |
| 收藏条目的备注 / 标题编辑 | 原版「列表框」有此能力；本版收藏只存位置与标签，面板展示时取回经文正文 |

## 八、已知的小瑕疵

1. **主题只改外壳**：切到浅色主题后顶栏 / 侧栏 / 面板变浅，经文区仍由「文字颜色 / 背景颜色」两项单独决定。
2. **浮动面板的「格式」页只有字号与主题两项**：其余显示设置（字体、标题、节号颜色、留白等）仍需在主窗口设置面板里调。
3. **两份 `DEFAULT_SETTINGS` 重复定义**（`src/main/main.js` 与 `src/renderer/js/state.js`）：字段名与默认值目前一致，改动时两处都要同步。
4. **两份经文 JSON 同时常驻内存**（各一份 31,102 节的 `Map`）：内存占用可接受，切换译本时不会重复读盘（已加载过的译本走缓存）。
5. **搜索为全表线性扫描**：31,102 节规模下可用，但不是索引结构。
6. **单字母快捷键在普通模式下被速选条占用**：`E`、`1`…`6`、`W` / `G` / `L` / `B` / `Y` / `R`、`Z`、`X`、`D` 只在投影 / 绘制模式下生效（与原版的字母输入优先一致）。
