## 项目简介

《语音投影圣经》是一款 2012 年前后的 Windows 查经 / 投影软件，在教会聚会中广泛使用。
它的可执行文件是原生编译的 VB6 程序，数据放在随程序分发的 Access 数据库 `bibleNosound.dat` 里。

本项目是**用现代技术栈对该软件功能的重新实现**（clean-room 重写），不是原程序代码的移植：

- 运行时换成 **Electron 33 + 原生 JavaScript**（无前端框架、无打包器、渲染层无构建步骤）
- 经文数据以 JSON 形式随仓库分发：**和合本**（简体 / 繁体，公有领域）开箱即用、**完全离线**；
  另外 4 个受版权保护的中文译本按需下载一次即可离线使用（见 [译本说明](docs/versions.md)）
- 内置 **3 个公有领域的译本**：和合本（简体 / 繁体，1919）与吕振中译本，随程序分发；另有 **4 个受版权保护的译本**可在应用内按需下载（见 [译本说明](docs/versions.md)）
- 界面、快捷键、显示设置按现代桌面软件重做，修复原程序遗留缺陷

## 为什么重写

原程序《语音投影圣经》5.20-SP2 无声版在 **VB6 原生编译**环境下存在一个致命缺陷：

> 在任何输入框中输入中文（VB6 内部按 ANSI / CP936 代码页处理字符串）都会抛出
> **`Run-time error '5'`（非法过程调用或参数错误）**，程序直接终止，无法恢复。

这意味着原版软件在查经中最常用的动作——**搜索中文关键字**——本身就是一个崩溃触发器；
更糟的是，这个缺陷发生在 ANSI 代码页转换链路上，与输入法的候选字、组合字符处理耦合，
在部分环境下甚至只要焦点进入输入框就可能触发。

VB6 的字符串模型是「按字节的 ANSI 字符串」，而 Windows 中文环境的系统代码页是 CP936（GBK）。
两字节字符在长度计算、截断与 API 边界之间反复换算，任何一次不匹配的假设都会把程序带进
未处理的运行时错误分支——VB6 对这类错误没有 `try/catch`，于是整个进程结束。

重写版彻底避开这条链路：全部文本以 UTF-8 在 Node / Chromium 中处理，不存在代码页转换，
中文输入只是普通字符串输入，不再有崩溃路径。

## 安装与运行

### 环境要求

- Windows 10 / 11（x64）；macOS / Linux 可运行源码但未提供官方安装包
- 开发需要 **Node.js ≥ 20**（CI 在 Node 22 与 24 上测试）

### 从源码运行

```bash
git clone https://github.com/fenghaichao/bible-projection.git
cd bible-projection
npm ci          # 或 npm install
npm start       # 启动应用
```

其他脚本：

| 命令 | 作用 |
| --- | --- |
| `npm start` | 启动 Electron 应用（`electron .`） |
| `npm run dev` | 以 `--dev` 标志启动（开发调试用） |
| `npm test` | 运行单元测试（`node --test test/*.test.js`） |
| `npm run build` | 打包 Windows NSIS 安装包，输出到 `release/` |
| `npm run pack` | 仅生成免安装目录版（`release/win-unpacked/`） |

> 渲染层是原生 JavaScript，**没有前端构建步骤**：改完 `src/renderer/` 下的文件刷新窗口即可生效。

## 打包 Windows 安装包

```bash
npm run build
```

使用 [electron-builder](https://www.electron.build/) 25 生成 **NSIS x64 安装包**，产物在 `release/`：

- `release/BibleProjection Setup x.x.x.exe` —— 安装包（可选择安装目录，创建桌面快捷方式「圣经投影」）

打包只收录 `src/`、`data/` 与 `package.json`（见 `package.json` 的 `build.files`）。

### 内置的 3 个译本（公有领域）

- **和合本（简体 / 繁体）**：1919 年出版，文字著作权已过保护期，属于**公有领域**，本项目可以自由复制、修改与再分发。
- **吕振中译本**：信望愛版权说明页（<https://www.fhl.net/main/fhl/fhl8.html>）记载，该译本 1952 年由香港圣书公会出版《新约新译修稿》、1970 年正式出版全书，**已超过中国著作权保护期 50 年，属公有领域**；信望愛模块清单 `abv.php` 中它的 `candownload` 标记为 `1`（开放离线下载授权）。因此它的正文（`data/versions/lcc.json`，31,081 节）**随仓库与安装包一并分发** —— 这也让 `data/` 目录从约 7.2 MB 增加到约 11.2 MB（+3.97 MB）。

### 需要按需下载的 4 个译本

- **和合本修订版 2010**（© 香港圣经公会）、**中文标准译本**（© 全球圣经促进会 GBI，注册商标）、**现代中文译本 2019**（© 联合国圣经翻译中文委员会）、**环球新译本**（© 环球圣经公会）的正文**受版权保护**，**不随本仓库与安装包分发**。有两种获取方式：
  1. **应用内下载**：顶栏「获取译本」→ 选中译本 →「下载安装」，程序会从**信望愛 FHL API**
     （<https://bible.fhl.net/api/qb.php>）逐卷取得经文并存到本机
     （`%APPDATA%\BibleProjection\versions\`），下载一次之后完全离线可用；
  2. **本地 JSON 导入**：「获取译本」面板底部「从本地文件导入…」，选择一份

  程序会在「获取译本」面板给它们加上**「需授权确认」**标签，点击「下载安装」时先弹确认框
  （写明版权方、FHL 未开放离线下载授权、仅供个人使用、需自行取得授权），确认后才开始下载。
- 正文版权归各自权利人所有；**下载并使用即表示你已自行取得使用授权**，使用前请自行核对各译本的授权条款。

数据目录说明见 [data/versions/README.md](data/versions/README.md)。

### 文本的取得方式

简繁两个版本的经文与卷目元数据来自原程序随附的 Access 数据库 `bibleNosound.dat`，
由 `tools/extract-mdb.ps1` 抽取为：

- `data/bible-simplified.json` —— 简体
- `data/bible-traditional.json` —— 繁体
- `data/versions/lcc.json` —— 吕振中译本（公有领域，随仓库与安装包分发）

数据库中的 `Bible` / `BibleF` 两张表各含 **31,102 节**经文（即和合本全书的节数），
`bibleid` / `bibleidF` 两张表各含 **66 卷**的书目信息。
抽取脚本与字段映射详见 [docs/data.md](docs/data.md)。

> 抽取脚本只用于**把原程序的数据转换成开放格式**。
> 它不包含原程序的任何代码；本项目不含原程序的可执行文件、资源或反编译产物。

需要按需下载的 4 个译本由 `tools/fetch-versions.py` 从**信望愛 FHL API** 抓取、`tools/clean-versions.js` 清洗，
然后由使用者自己决定放在哪里（**不进仓库、不进安装包**）：

```bash
python tools/fetch-versions.py                      # 重新抓取全部译本（需要联网）
python tools/fetch-versions.py --versions rcuv,csb  # 只抓指定译本
python tools/fetch-versions.py --out D:\vers        # 抓取到指定目录
node tools/clean-versions.js D:\vers                # 清洗抓取结果
node tools/verify-versions.js D:\vers               # 校验译本文件的结构
```

> `tools/fetch-versions.py` 是**用户侧**的取数辅助脚本（Python 3 + 网络），
> 不参与打包，也不进入 CI。抓取结果默认写入 `%APPDATA%\BibleProjection\versions\`，
> 应用内「获取译本」面板的下载功能调用的也是同一个 API。

## 已知限制

- **没有语音朗读。** 原程序的「无声版」本就不含朗读与 LRC 同步功能，本项目保持一致。
- **只提供 Windows 安装包。** `npm run build` 目前只配置了 NSIS x64 目标；macOS / Linux 需自行用 electron-builder 配置目标，或从源码运行。
- **经文文本沿用原程序数据库的内容**，未与公开的电子和合本逐字校对；个别用字与标点可能与现代通行本有出入。
- **不支持同时在多个窗口显示不同经文**（原版有此功能），当前为单窗口 + 一个浮动控制面板；需要并排比较时用「多版本对比」。
- **无线遥控器没有做硬件适配**，但键盘媒体键（上一曲 / 下一曲）可以当翻节遥控使用。
- **原版的透明窗口（`F7`）与桌面扩展（`F9`）没有实现**：这两种窗口形态依赖主进程 `BrowserWindow` 的额外能力，本版未做；投影请用 `F5`，系统原生全屏用 `F11`。显示区右键菜单保留了「扩展桌面_F9」条目，点击会提示本版改为「投影到副屏」。
- **原版 `Ctrl` + `0`…`4`「隐藏全部对照栏」的语义被替换**：本版**已移除对照栏功能**（按要求删除），`Ctrl` + `0` 用于复位字号。
- **除已内置的 3 个译本（和合本简 / 繁、吕振中）外，其余 4 个译本需要联网下载一次**（应用内「获取译本」→「下载安装」，数据来自信望愛 FHL API，下载前需确认已自行取得授权），下载到本机后即可离线使用。
- **各译本分节不同**（31,061 – 31,102 节），应用不跨译本用节号定位经文，历史 / 收藏 / 标注条目只记「卷:章:节」的位置（正文随译本变化）。
- **多版本对照时各译本的分节并不一致**：同一节号在个别译本中可能不存在或内容不同，对照时以各译本自身的分节为准。
- **下载入口指向第三方 API**（信望愛 FHL），其可用性、返回内容与访问政策不由本项目保证；使用前请自行确认各译本的授权条款。
